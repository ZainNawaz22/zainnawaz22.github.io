About

I'm Zain, a software developer based in Pakistan with a Computer Science background at FAST NUCES (batch of 2022). My projects span web, mobile, and desktop applications, alongside machine learning and C++ games.

My work includes PSX AI Advisor, a Python and FastAPI project for stock analysis and machine learning predictions, and a React and TypeScript frontend for market data. I also built Instant Grader Pro, a Flutter app that uses computer vision to read multiple-choice answer sheets.

In C++, I've built Maintendance, a Qt desktop application for attendance and leave management, as well as an OpenGL first-person game and Space Invaders. These projects have given me practice with application workflows, graphics, and game logic.

I enjoy connecting the processing behind an application with an interface people can use, whether that's a stock dashboard, an answer-sheet scanner, or a desktop tool. You can explore the code for my projects below or get in touch by email.
